## Active Directory NTLM Attack & Defense Lab

# A Practical Active Directory Security Assessment and Hardening Project

An hands-on cybersecurity lab exploring Active Directory authentication security, SMB protocol weaknesses, NTLM credential exposure, and common authentication attack techniques. The project demonstrates how these weaknesses can be identified, assessed, and mitigated in a controlled Windows domain environment.

---

## Project Overview

This lab focuses on understanding and testing Windows domain authentication mechanisms, with particular attention to NTLM and SMB security. It combines practical attack simulations with defensive security measures to demonstrate the importance of securing enterprise authentication infrastructure.

## Technical Scope

- Active Directory: Domain environment, user management, and authentication.
- SMB Enumeration: Identifying exposed SMB services and shares.
- NTLM Authentication: Understanding NTLM challenge-response authentication.
- Responder: Simulating authorized LLMNR/NBT-NS poisoning and credential capture scenarios.
- Pass-the-Hash: Exploring NTLM hash-based authentication risks.
- Credential Security: Examining credential exposure and authentication weaknesses.
- Security Hardening: Applying defensive measures to reduce NTLM-related attack surfaces.

Project Objectives

1. Understand how Active Directory handles domain authentication.
2. Identify security weaknesses associated with SMB and legacy name-resolution protocols.
3. Demonstrate NTLM-related attack techniques in a controlled lab.
4. Evaluate the security implications of exposed authentication material.
5. Implement and document defensive hardening recommendations.
